# LUMA | Ultra-Luxury Real Estate Landing Page Template

LUMA is a state-of-the-art, high-conversion landing page template designed for elite real estate developments, high-end estates, and architectural masterpieces. Built with **Next.js/React**, **Framer Motion**, and **Tailwind CSS**, it delivers a cinematic browsing experience that mirrors the luxury of the properties it showcases.

## ✨ Key Features
- **Cinematic 3D Gallery**: A custom-engineered, scroll-synced circular 3D dial for property showcases.
- **Micro-Interaction Design**: Smooth parallax effects, glassmorphic UI elements, and scroll-triggered animations.
- **Config-First Architecture**: Change the entire site brand, content, and links from a single file (`src/config/site.ts`).
- **Responsive Excellence**: Pixel-perfect presentation on everything from 4K monitors to high-end mobile displays.
- **Lead Capture System**: Premium glassmorphic contact form designed for high-net-worth conversion.

## 🚀 Quick Setup
1. **Install Dependencies**: `npm install`
2. **Launch Dev Server**: `npm run dev`
3. **Customize Content**: Open `src/config/site.ts` and replace the placeholder text/images with your own.

## 🛠 Project Structure
- `src/config/site.ts`: **The Source of Truth.** Edit this first.
- `src/components/ui/`: Reusable high-fidelity UI components.
- `src/components/CircularGallery.tsx`: The core 3D interactive core.
- `src/assets/`: Store your high-res videos and images here.

## 📦 Commercial Value
This template is optimized for high-end boutique agencies. By using the centralized config, you can deploy a customized version for a client in **less than 15 minutes**, allowing you to charge professional architectural visualization rates with minimal overhead.
